# Green Group

Новый отдельный сайт строительно-промышленного холдинга Green Group. Источники: https://green-groupp.ru/ и официальный сайт проекта https://beldom.pro/, указанный в материалах компании.

## Запуск

Node.js 22+: `npm run dev` (порт 4197), `npm run check`, `npm run build`. Результат — статическая папка `dist/`. Vercel подключён к ветке main репозитория Standartrealty/green-group.

## Состав

Первый экран с пользовательским видео, затемнением и кнопкой паузы. Семь проектов с описаниями и галереями; восемь SVG-планировок Белого дома с фильтрами и увеличением; подбор квартиры; условия покупки; четыре завершённых проекта; направления холдинга; сервис и инфраструктура; официальные материалы; новости; вакансии; отзывы Яндекс; FAQ; карта и контакты четырёх направлений. Мобильная версия включает верхнее меню и нижнюю панель из пяти действий.

Для остальных проектов схемы запрашиваются в отделе продаж. Цены и наличие не выдумывались. Формы демонстрационные — данные не отправляются и не сохраняются. Реальные обращения доступны через официальные телефон, WhatsApp, Telegram и почту. Vercel Authentication сохранён по ранее выбранному пользователем режиму.

## Архив

Локальная папка `source-content/` содержит 26 HTML-страниц с текстовыми снимками и 244 сохранённых ресурса, включая варианты размеров и материалы официального сайта Белого дома. `catalog.json` связывает URL с файлами и фиксирует ошибки. Полный архив оригиналов остаётся в рабочей папке пользователя; GitHub содержит оптимизированные материалы сайта, снимки текста и каталоги источников.

`source-content/usage-manifest.json` фиксирует использованные изображения, `reviews-verified.json` — проверенные сведения об отзывах. Подробности и расхождения — в `VERIFICATION.md`.

Видео — предоставленная пользователем видеоиллюстрация, не подтверждённая съёмка проектов Green Group. Водяной знак сохранён. При reduced-motion или data-saver доступен постер и ручное воспроизведение.

Опубликованный сайт: https://green-group-five.vercel.app/
